# Путь знаний — Rover

Браузерный 3D-раннер по Иннополису: собирайте верные ответы и объезжайте неверные.

Игра: https://plairpro.github.io/rover/

Версия Почтатеха: https://plairpro.github.io/pochtatech/

В обеих версиях финальное здание отмечено анимированными лучами. Версия Почтатеха использует белый и синий (#0055ff); точный фирменный оттенок ожидает предоставленного образца.

## Запуск

```bash
npm ci
npm run dev
```

Откройте http://localhost:4173. Нужен Node.js 18 или новее.

## Структура

- `pochtatech/index.html` — перенаправление на https://plairpro.github.io/pochtatech/. Ресурсы новой версии остаются в `pochtatech/assets/` и `dist/assets/`.
- `dist/index.html` — сцена Three.js, интерфейс и механика.
- `dist/assets/rover-music.mp3` — предоставленная владельцем фоновая мелодия, сжатая до mono MP3 32 kbit/s, 22.05 kHz (~616 КБ).
- Корневой `index.html` перенаправляет GitHub Pages на `dist/`.

Сборка не требуется. Для другого статического хостинга загрузите папку `dist` вместе с `assets`. Three.js и шрифты загружаются с CDN. Остальные модели, текстуры и звуковые эффекты создаются программно.

## Правила и управление

- 16 задач на трассе длиной 1020 единиц: первые задачи простые, ближе к финишу появляются два действия, скобки и сочетания умножения с другими операциями.
- В каждом заезде меняются числа, отвлекающие ответы и глубина кубов. Верная полоса никогда не повторяется подряд; распределение по полосам сбалансировано.
- Телефон: тап по левой или правой половине игрового экрана. Бледные круги отмечают направления. Свайп не требуется.
- Компьютер: клики по половинам экрана, стрелки либо A / D; пробел начинает заезд.
- После верного ответа целевая скорость повышается на 0.8; фактическая скорость растёт плавно от 16 до 28.8.
- Верный куб зеленеет, поднимается и исчезает с частицами и мелодичным сигналом.
- Три столкновения с неверными кубами приводят к остановке и поломке с дымом. Искры показывают оставшиеся попытки.
- Кнопка ♪ / ♫ отключает или включает весь звук. Музыка звучит тихо во время заезда; электромотор меняется со скоростью и манёврами. При скрытии вкладки звук приостанавливается.

## Проверки

Программно проверены 320 выражений, распределение ответов, обработка тапов без повторного клика, полный успешный заезд, плавное ускорение, зелёный подбор, поломка и перезапуск. Реальная отзывчивость на конкретных телефонах, визуальная/слуховая оценка и мобильный FPS требуют проверки на устройствах.
